# CS264 การประมวลผลภาพเชิงดิจิทัล: โปรแกรมประกอบตำรา

โปรแกรมตัวอย่างทั้ง 49 โปรแกรม (โปรแกรม 1.1–8.6) จากตำรา "การประมวลผลภาพเชิงดิจิทัล" โดย นาวาอากาศตรี ผู้ช่วยศาสตราจารย์ ดร.ปธิกร อันชื่น โรงเรียนนายเรืออากาศนวมินทกษัตริยาธิราช พ.ศ. 2569

## สภาพแวดล้อมที่ทดสอบ
Python 3.13, OpenCV 4.14.0, NumPy 2.5.3, scikit-image 0.26.0 (ดู `requirements.txt`)

```
pip install -r requirements.txt
```

## วิธีใช้
แต่ละบทมีหนึ่งไฟล์ในโฟลเดอร์ `chNN/` เรียงโปรแกรมตามลำดับในตำรา ให้รันไฟล์ในโฟลเดอร์ว่าง เพราะโปรแกรมหลัง ๆ ใช้ฟังก์ชันและไฟล์ที่โปรแกรมก่อนหน้าสร้างไว้ (เช่น `edge_lib.py` ของโปรแกรม 4.4)

```
mkdir work && cd work
python ../ch04/ch04_programs.py
```

ภาพทดสอบดึงจากไลบรารี scikit-image (`skimage.data`) ไม่ต้องดาวน์โหลดภาพเพิ่ม ภาพที่โปรแกรมสร้างเองถูกจำลองในโค้ด
